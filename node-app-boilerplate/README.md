# Full-Stack Node.js Boilerplate

A production-ready folder structure and starter setup for a Node.js backend and modern frontend.

## Project Structure

```text
node-app-boilerplate/
├── backend/          # Node.js + Express API
└── frontend/         # Frontend Client App
```

## Getting Started

### Backend Setup
1. `cd backend`
2. `npm install`
3. Copy `.env.example` to `.env` and set your environment variables.
4. `npm run dev` to start the development server on `http://localhost:5000`.

### Frontend Setup
1. `cd frontend`
2. `npm install`
3. Copy `.env.example` to `.env` and set your backend API URL.
4. `npm start` to run the frontend app.

## Features
- Controller-Service-Model architecture on Backend
- Pre-configured Express server with Error Middleware & CORS
- Clean Modular Frontend components structure
